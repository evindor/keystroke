READY WHEN YOU ARE.

One command.
A whole new flow.

Requires Omarchy 4.0.2 or newer, with its plugin system.

YOUR TERMINAL
omarchy plugin add https://github.com/evindor/keystroke.git --enable

Then press Super + Space. You’re in.

Enable voice control +

Install voxtype through Omarchy → Install → AI → Dictation, then open Keystroke Settings → Voice and enable the hold-to-talk bindings. A second tap of your shortcut can also start listening.

Keystroke uses your normal Voxtype service and settings without replacing or rewriting them. Current releases fill the query after transcription finishes; live partials will appear automatically when supported upstream.

Full voice setup ↗
Connect Codex +

Install the supported Codex CLI (0.153.2) and sign in with codex login. Type ? before your question or select Ask Codex here.

The integration uses your Codex access and its usage limits. Choose the model, processing tier, and handoff destination in Settings → Codex.

Compatibility and setup ↗
Add your first extension +

Type ext, open Extensions, and browse Discover. Start with Timer, or enter a plugin’s git URL. Review and confirm the installation.

Extensions run unsandboxed with your permissions, just like other Omarchy plugins.

Explore the Timer template ↗
Restore the default menu +

To disable Keystroke and restore the stock Omarchy menu:

omarchy plugin disable evindor.keystroke

To remove it completely:

omarchy plugin remove evindor.keystroke

File search uses fd. Clipboard history uses Omarchy’s existing history. Keystroke and its extensions run with your user permissions. Read the install notes ↗
