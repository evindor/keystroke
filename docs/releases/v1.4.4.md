# Keystroke 1.4.4

Released September 20, 2026.

A quieter results list. A row no longer changes when you select it: the
keys that act on it are listed in the footer, where they always were for
`↵`, and the extension badge and the "History" tag that used to crowd the
title are gone. The preview pane on the right opens only when it has
something to show, so files, folders and browser pages run the full width.
Confirmations rise from the bottom of the card as a sheet with the two keys
named for what they do.

## Improvements

- **The footer lists every key for the selection.** `↵` with the row's verb,
  `Ctrl+↵` with what the alternate does (`Copy URL` on a browser page, `Open
  terminal` on a file, `Paste` on a translation, `Turn off` on an extension
  that is on, `Open task in Codex`), `Del` to uninstall an application, and
  `Ctrl+K` for the provider's settings. A command row, whose text both `↵`
  and `Tab` type, shows the two keys under one verb. Rows never spell keys
  out themselves any more: the free-text `hint` is gone from every provider
  and extension, replaced by a structured `altVerb` that names the
  `Ctrl+↵` action.
- **Rows carry only what is theirs.** The `extension` badge moved off the
  title into the preview pane, beside the detail line; the "History" and
  "Bookmark" tag on browser pages is gone, since the icon and the section
  already say it. What stays on the right of a row is state (a check mark,
  a setting's value, a countdown) or a chevron on a row that opens a
  screen. Selecting a row changes its highlight and title weight, nothing
  else.
- **The preview pane opens only when it adds something.** Files and folders
  carry a preview only for images; browser pages carry none. Calculator,
  converter, colours, emoji, clipboard, timers, translations and currency
  keep theirs. Everything else takes the full width of the card.
- **Confirmations are a sheet.** Turning an extension on, cancelling a
  timer, running a destructive Omarchy action or uninstalling an
  application now asks from the bottom of the card, under an accent rule,
  with the results dimmed above: the question, the note, and `↵` and `Esc`
  named for what they do (`Turn on` / `Keep off`, `Cancel timer` / `Keep
  running`, `Uninstall` / `Keep it`). `↵` always runs and `Esc` always
  keeps; Left and Right no longer move a focus between two buttons.
- **Provider contract.** Rows may set `altVerb`, `confirmText` and
  `cancelText`; `hint` is ignored. [docs/providers.md](../providers.md)
  says when a row should carry a preview at all. Every site and README
  screenshot is re-rendered.

## Update

```sh
omarchy plugin update evindor.keystroke
omarchy restart shell
```

Requires Omarchy 4.0.2 or later. Everything in the
[1.4.0 notes](v1.4.0.md) applies unchanged. The bundled matching engine is
byte for byte the one verified in 1.4.2.

Validation: `bin/keystroke test` (the QML suite, the extension checks, the
matching engine check, the palette checks for URLs, shortcuts, extensions,
commands and dictation, qmllint) and plugin validation pass. See the
[verification record](../verification.md).
