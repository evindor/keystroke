# Keystroke 1.4.1

Released September 11, 2026.

A documentation release: the usage guide's copy was rewritten to read like a
manual. Nothing in the plugin's code changes between 1.4.0 and 1.4.1 except
the version in `manifest.json`.

## Changes

- **The usage guide reads like a manual.** Section headings on
  [evindor.github.io/keystroke/guide](https://evindor.github.io/keystroke/guide/)
  now say what each feature does (*Convert units and temperatures*, *Type any
  emoji*, *Find files and folders*, *Countdown timers*, *Translate text*), the
  introduction says what the page is, and the lines that sounded like an
  advertisement are gone. Four headings keep their tone on purpose: *One key.
  Everything.*, *Hands stay on the keyboard.*, *Shortcuts you have not learned
  yet.* and *Your voice. Same superpowers.*

## Update

```sh
omarchy plugin update evindor.keystroke
omarchy restart shell
```

Requires Omarchy 4.0.2 or later. Everything in the
[1.4.0 notes](v1.4.0.md) applies unchanged.

Validation: the site preflight (both pages, every anchor and asset), the
162 QML tests and plugin validation pass; the code is identical to 1.4.0.
See the [verification record](../verification.md).
