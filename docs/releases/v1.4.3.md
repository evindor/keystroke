# Keystroke 1.4.3

Released September 20, 2026.

A web address typed into the palette now opens in your browser, and two new
extensions join the box, off until you turn them on: Browser search (your
default browser's history and bookmarks) and GIF Search (GIPHY, copied to the
clipboard). Keyboard Cleaner learned to keep a wipe from opening the power
menu, sticking a key or tripping the lock screen. One fix for Delete on a
selected application.

## New

- **Open URL.** Type or paste a web address (`example.com/path?q=hello`, with
  or without `http(s)://`) and it appears above ordinary matches; `↵` opens it
  in your default browser, `$example.com` selects the provider directly.
  Domains default to HTTPS, bare IP addresses and `localhost:3000` to HTTP;
  international domains, IPv6 literals in brackets, ports, queries and
  fragments are kept as typed. Only `http` and `https` can reach a launch:
  `javascript:`, `data:`, `file:` and `mailto:` are refused, as is anything
  carrying whitespace, control characters or shell punctuation, and the URL
  reaches `xdg-open` as one literal argument. A bare file name stays a file:
  `readme.md` and `archive.zip` find your files rather than offering an
  address, while a scheme, `$`, a port or a path asks for the address anyway.
  Settings → Open URL has **Enabled** and **Prefix**.
- **Browser search** ([extensions/browser-search](../../extensions/browser-search/)):
  words from a page's title or URL find it in your default browser's history
  and bookmarks, from the main palette or with `browser github`. `↵` opens
  the page, `Ctrl+↵` copies the link. The default browser comes from
  `xdg-mime`; Chromium, Chrome, Brave, Vivaldi, Edge and Firefox are read in
  their native and Flatpak locations, every profile, read-only, with no
  copies, caches or network. A browser that is running keeps its history
  locked, so the reader falls back to SQLite's `immutable=1` and reads the
  file without taking a lock. **Search history** and **Search bookmarks**
  are separate switches. Needs `python3` and `xdg-utils`.
- **GIF Search** ([extensions/gif-search](../../extensions/gif-search/)):
  `gif thank you` opens a three-column animated grid of GIPHY results (`gif`
  alone shows trending); `↵` copies the GIF to the clipboard as `image/gif`
  through `wl-copy`, `Ctrl+↵` copies its link, Previous/Next page through 24
  at a time. Settings choose which of the two `↵` does and whether the view
  closes after a copy. Every media URL is checked against giphy.com before it
  is shown, and the copy helper streams the original to the clipboard,
  rejecting anything that is not a GIF or is over 25 MB. Searches go to the
  public GIPHY proxy Raycast runs for its own GIF extension, without an API
  key; the README says so and notes that its availability is not
  guaranteed. Needs `curl`, `python3` and `wl-clipboard`.

Both extensions ship switched off and are never compiled while off.

## Improvements

- **Keyboard Cleaner 1.1.0**, by [ozz1ee](https://github.com/ozz1ee-dev):
  a wipe is not typing, and the block now leaves the session alone while it
  runs. The power and lid node goes inside the block, because on Apple
  hardware Hyprland lists it as a keyboard and a cloth brushing the power
  key opened Omarchy's power menu, where the next stray key ended the
  session; the lid switch is a separate device and keeps working. A block
  waits for every key to come up and refuses to start while one is held,
  since a key held when its device goes dead never delivers its release and
  read as stuck for the whole block. Idle is parked with
  `omarchy-shell idle disable` for the duration and handed back afterwards,
  so a five-minute wipe no longer lands on the screensaver or a lock prompt
  you cannot type into; a block killed outright is un-parked the next time
  the extension loads, and a stay-awake you set yourself is never cleared.
  `bin/keyboard-cleaner --dry-run` prints what a block would cover. The
  README records Omarchy's Caps Lock mapping (Compose on the key, the lock on
  both Shifts) and the rule that a block covers exactly the time it is set
  for.

## Fixed

- **Delete on a selected application** now opens the uninstall confirmation
  even after you typed a filter; it used to require an empty query, so the
  `Del uninstall` hint on the row did nothing once you had narrowed the list.
  By [Andrew Birklid](https://github.com/tumbleweedlabs). Delete in the
  middle of the query, or over a selection, still edits the text.

## Update

```sh
omarchy plugin update evindor.keystroke
omarchy restart shell
```

Requires Omarchy 4.0.2 or later. Everything in the
[1.4.0 notes](v1.4.0.md) applies unchanged. The bundled matching engine is
byte for byte the one verified in 1.4.2.

Validation: `bin/keystroke test` (the QML suite, the extension checks, the
matching engine check, the palette checks for URLs, shortcuts, extensions
and commands, qmllint) and plugin validation pass. See the
[verification record](../verification.md).
