# Keystroke 1.5.2

Released October 24, 2026.

Copied text no longer passes through a command line, where other users of the
same machine could read it. Also in this release: a search engine of your
choice with a `g` command to go straight to it, a hibernate that file search
can no longer block, GIF previews that cannot crash the shell on Qt 6.12, and
Chrome bookmarks that show up again. Thanks to Christian Dandachi, Johan, Billy
JR and Cameron Ring, who found, wrote or proposed them.

## Security

- **Copied text stays off the command line.** Copying a clipboard-history
  entry (or a calculator answer, an emoji, a colour) handed the whole text to
  `wl-copy` as an argument, and any local user can read a running process's
  arguments in `/proc`. It now goes to `wl-copy` on stdin, the way paste and
  dictation already did. The same goes for text typed at an
  `omarchy-menu-input` prompt on its way back to the calling script, and for
  Translate's copy and paste (Translate 1.0.2). Reported in the marketplace
  review of 1.5.1.

## New

- **Pick your search engine; `g` searches it directly** (proposed by Cameron
  Ring). Settings → AI & Web Search → **Search engine** switches the search
  under every query from Google to DuckDuckGo, Brave, Bing or Startpage.
  `g rust lifetimes` skips everything else and returns only that search;
  rename `g` under **Prefix**. `Ctrl+↵` copies the URL.

## Fixes

- **Hibernate is no longer blocked by file search** (by Christian Dandachi).
  A file search still running in the background could get stuck on a cloud
  or network mount under your home folder and stop the system from
  hibernating. Searches now stop when the palette closes, runs an action or
  changes screen, and stay off other filesystems unless you turn on
  Settings → Files → **Search mounted filesystems**.
- **GIF previews cannot crash the shell** (by Johan). On Qt 6.12, a GIF
  preview restarting at its end could recurse until the whole shell crashed.
  Previews now cache their frames, unload when scrolled out of view, and keep
  each GIF's shape. GIF Search 1.1.3.
- **Chrome bookmarks show up again** (by Billy JR). Chrome keeps bookmarks
  saved to your Google Account in a separate file, so Browser search found
  none of them in a signed-in profile. Both files are read now, without
  duplicates. Browser search 1.1.1.

## Update

```sh
omarchy plugin update evindor.keystroke
omarchy restart shell
```

Requires Omarchy 4.0.2 or later. Everything in the [1.4.0 notes](v1.4.0.md)
applies unchanged. The bundled matching engine is byte for byte the one
verified in 1.4.2. The search row's id changed from `google` to `search`, so
its learned rank starts fresh.

Validation: the QML suite (278 tests), the extension checks for all ten
extensions, the palette, clipboard, Codex, matching, graphics-loss and hotkey
checks, the new copy and web search checks, qmllint and plugin validation pass
on Qt 6.11. See the [verification record](../verification.md).
