# Keystroke 1.4.2

Released September 11, 2026.

The compiled Smart Match engine that ships with Keystroke is now built in a
pinned container, rebuilt and compared byte for byte by CI on every push, and
attested on releases, so anyone can check that the binary comes from the
source in the same commit. Two contributed extensions join the box, off until
you turn them on: Currency and Keyboard Cleaner. Two small fixes for select
pickers and time-zone lookups.

## Changed

- **The matching engine is reproducible.** `matching/bin/keystroke-matching`
  is the same engine as before (Rust, `matching/engine`), now built for
  `x86_64-unknown-linux-musl` inside `rust:1.98.1-alpine3.22` pinned by
  digest, linked with the toolchain's own `rust-lld` and bundled C runtime,
  with cargo paths remapped. Nothing from the machine that ran the build
  reaches the bytes. `matching/engine/build-prebuilt.sh --check` rebuilds it
  in that image and fails unless the result equals the committed file; the
  new [engine workflow](../../.github/workflows/engine.yml) runs that check on
  every push and pull request, and on `main` and release tags records a
  GitHub build provenance attestation for the committed binary. The binary
  shrank from 1.5 MB to 695 KB. Users still need no Rust toolchain: the
  binary is in the plugin, and the fallbacks (a local `cargo` build on other
  architectures, the Python runtime through `uv`) are unchanged.
  [docs/engine-provenance.md](../engine-provenance.md) has the reproduce and
  verify commands.

## New

- **Currency**, by [Gunhan Selas](https://github.com/gunhanselas):
  `100 usd to eur`, `$100 in try`, `129usd` into your preferred currency.
  The rates are the European Central Bank's reference rates from
  [Frankfurter](https://frankfurter.dev), fetched with `curl` once a day the
  first time you convert something and kept for offline use. Enter copies
  the result, Ctrl+Enter the bare number. A download that returns nothing is
  now recorded as a failure and not retried for ten minutes.
- **Keyboard Cleaner**, by [ozz1ee](https://github.com/radiohost-cloud):
  `wipe 30s` switches every keyboard and pointer off through `hyprctl` for
  the time you name (5 minutes at most), shows a countdown in the palette,
  and switches them back on; the same without the prefix (`block 2m`) is
  offered as a *Continue with* row. No privileges involved.

Both live under [extensions/](../../extensions/), ship switched off, and are
never compiled while off.

## Fixed

- **Select pickers with no matching rows** kept only one row of height, so
  the empty-state glyph and message were cut off. The picker now reserves
  room for them. By [Andrew James](https://github.com/andrew-t-james-wc).
- **Time zones with one name in two regions** (`Istanbul` is both
  `Asia/Istanbul` and `Europe/Istanbul`) no longer ask which you meant when
  every match has the same offset right now. By Gunhan Selas.

## Update

```sh
omarchy plugin update evindor.keystroke
omarchy restart shell
```

Requires Omarchy 4.0.2 or later. Everything in the
[1.4.0 notes](v1.4.0.md) applies unchanged.

Validation: `bin/keystroke test` (the QML suite, the extension checks, the
matching engine check, the palette checks for currency and select pickers,
qmllint) and plugin validation pass; the engine workflow reproduced the
shipped binary byte for byte on dev. See the
[verification record](../verification.md).
