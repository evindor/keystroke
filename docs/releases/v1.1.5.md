# Keystroke 1.1.5

Released September 9, 2026.

This release restores the Applications list on Omarchy 4.0.3, keeps compatibility
with 4.0.2, and brings the latest time-zone, voice and extension improvements from
`dev` to `main`.

## Fixes

- **Applications on Omarchy 4.0.3.** Cloned menus can receive a shell API with no
  app library because of an upstream manifest conversion bug. Keystroke now uses
  Omarchy's installed app-library component when the shared library is missing,
  preserving native hidden-app filtering, icons, launch feedback and removal.
  The shared-library path remains preferred on 4.0.2 and hosts that provide it.
  Upstream tracking: [issue #10661](https://github.com/omacom/omarchy/issues/10661)
  and [PR #10785](https://github.com/omacom/omarchy/pull/10785).
- **Provider views retain the palette border and typography.** Embedded views,
  including Codex conversations, stay inside the card's border and use the same
  theme-driven text scale as the rest of the palette.

## Improvements

- **More natural time-zone queries.** Use abbreviations (`10am pt`), city and
  country names, IANA zones, UTC offsets, `noon`, `midnight`, and natural dates
  such as `tomorrow 10am pt`. Current-time queries such as `now in tokyo` refresh
  while displayed. Ambiguous zones and daylight-saving transitions get useful
  hints.
- **Standard Voxtype integration.** Keystroke uses the ordinary `voxtype` on your
  `PATH`. It no longer ships the fork installer or prefers an old Keystroke-owned
  binary. Your Voxtype configuration and service remain under your control.
  Completed dictation fills the query; live partials depend on support from the
  installed daemon. The `bin/keystroke voice-setup` command has been removed.
- **Richer extensions.** Providers can declare query patterns, use image icons,
  and supply embedded views through the documented API 1 contract. Calpad joins
  the extension index, and local `file://` Git repositories are supported for
  extension development.
- **Application diagnostics.** Palette inspection includes app-library
  availability and entry counts to make compatibility problems easier to trace.

## Update

```sh
omarchy plugin update evindor.keystroke
```

If the shell still uses cached plugin code after updating, run
`omarchy restart shell`.

Requires Omarchy 4.0.2 or later. Application compatibility was verified live on
Omarchy 4.0.3-1 with 73 visible apps. The 4.0.2 shared-library path is covered by
regression tests; a separate 4.0.2 desktop was not tested for this release.

Validation: 119 QML tests, 48 time-zone cases, application/voice/clipboard/Codex/
palette/extension integration checks, the live hotkey check, plugin validation,
site checks and qmllint passed. See the [verification record](../verification.md).
